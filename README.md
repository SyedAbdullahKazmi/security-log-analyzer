# Security Log Analyzer and Automated Alert System

## Overview
A project that analyzes security logs,
detects suspicious activity, and generates automated alerts.

## Objectives
- Generate security logs.
- Normalize log records.
- Detect suspicious activity using rule-based detection.
- Generate alerts with severity and evidence.
- Store and summarize alerts.

## Technologies
- Python
- SQLite
- CSV and JSON
- Git and GitHub
- VS Code
